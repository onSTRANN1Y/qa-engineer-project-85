# Тестирование Codebattle (codebattle.hexlet.io)

Учебный QA-проект: ручное тестирование веб-приложения [Hexlet Codebattle](https://codebattle.hexlet.io) — платформы, где два игрока соревнуются в решении задач по программированию.

В репозитории собраны тест-кейсы, которые я написал в процессе обучения тестированию ПО.

## Цель проекта

- Потренироваться в написании понятных тест-кейсов.
- Проверить безопасность передачи данных и скрытость информации о сопернике.
- Проверить поведение форм при некорректных данных.

## Формат тест-кейса

Каждый тест-кейс описан в YAML и содержит поля:

```yaml
- summary: |            # Краткое название: что проверяем
  requirement: |        # Требование, на которое опирается проверка
  prerequisites:        # Что должно быть готово до начала
    - ...
  test-data: |          # Адреса страниц, логины, вводимые значения
  steps:                # Пошаговые действия
    - ...
  expected-result: |    # Что должно получиться
```
